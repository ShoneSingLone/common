# xTableEasy 表头过滤面板"错位"修复记录

- 修改日期：2026-08-01
- 修改人：AI 助手（经用户确认执行）
- 涉及文件：`statics/common/ui-x/components/data/xTableEasy/header/header-filter-content.vue`

## 问题现象

虚拟滚动表格（ve-table/xTableEasy）表头的过滤功能"错位"：

1. 所有列的过滤面板**同时显示**（6 个下拉全部展开、叠在表头里）；
2. 过滤面板是**内联渲染**（`position: static`）在 sticky 表头 `th`
   里，没有浮层定位，方法列的高面板向下溢出表头、压住数据行。

## 根因

`header-filter-content.vue` 渲染 `xDropdown` 时，`dropdown` 插槽用的是**普通 `<div>`**，而项目标准做法（参照
`statics/common/ui-x/common/xTableFilter.vue`）应使用 **`xDropdownMenu`**。

`xDropdownMenu` 承担两个关键职责：

- **显隐控制**：监听 `xDropdown` 广播的 `visible`，用 `v-show="showPopper"` 控制，未展开时隐藏；
- **浮层定位**：混入 `VuePopper`（默认 `appendToBody`，PopperJS 定位），把菜单定位为覆盖层、浮在过滤图标下方。

裸 `div` 无上述能力，故所有面板同时内联显示且错位。

## 修改内容

1. 依赖中引入 `xDropdownMenu`（`/common/ui-x/components/navigation/xDropdown/xDropdownMenu.vue`）；
2. `xDropdown` 增加 `trigger: "click"`（与 `xTableFilter.vue` 一致）；
3. dropdown 插槽由裸 `div` 改为 `xDropdownMenu` 包裹 `ve-table-filter-content`。

## 验证结果（浏览器实测）

- [x] 过滤面板默认隐藏（之前 6 个全部同时显示）
- [x] 点击某列过滤图标，仅展开该列面板
- [x] 面板为浮层定位（Popper，appendToBody），`bottom-end` 对齐过滤图标
- [x] 点击面板外部可关闭面板（clickoutside）
- [ ] 确认按钮触发 `filterConfirm` 后的数据过滤（由页面列配置的 `filter.filterConfirm` 决定，本次未改动）
